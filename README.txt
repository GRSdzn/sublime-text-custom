Перенос настроек Sublime Text на Windows

1. Установите Sublime Text и один раз запустите его.
2. Установите Package Control: Tools → Install Package Control. Дождитесь установки.
3. Закройте Sublime Text. Сохраните резервную копию существующей папки %APPDATA%\Sublime Text\Packages, если на этом компьютере уже есть нужные настройки.
4. Вставьте путь %APPDATA%\Sublime Text в адресную строку Проводника. Скопируйте папку Packages из этого архива в открывшуюся папку Sublime Text и согласитесь на объединение. При запросе замены файлов учтите, что архив содержит пользовательские Preferences, keymap, настройки Terminus и Package Control.
5. Откройте Sublime Text и дождитесь, пока Package Control скачает пакеты из списка: Terminus, A File Icon, ayu и Material Theme. Для установки требуется интернет и доступ к packages.sublimetext.io. При необходимости перезапустите редактор.
6. Откройте меню «Тема» или нажмите Ctrl+Alt+Shift+T для смены светлой и тёмной темы. Ctrl+` открывает панель Terminus. Новые терминалы используют PowerShell.

Пакет содержит настройки, ресурсы темы и плагин переключения. Папки проектов, история редактора, содержимое .env и учётные данные не включены. Для пункта «Открыть в Sublime Text» в контекстном меню воспользуйтесь опцией установщика Sublime Text на новом компьютере. Если опции для папок нет, настройте её отдельно с учётом пути установки.

Архив является снимком на момент создания. После изменения настроек создайте новый экспорт или сохраните папки Packages\User, Packages\IDE Theme Toggle и Packages\niceDarkTheme отдельно.
